# 美学收集馆 / Aesthetic Museum

面向设计师的风格研习馆：以**固定舞台滚动叙事**（pinned-stage scrollytelling）呈现美学流派与经典参照。

**技术栈：** React、Vite、Tailwind CSS。

## 设计与协作规范

- [`AGENTS.md`](./AGENTS.md) — 仓库结构、开发约定与博物馆体验规则摘要  
- [`docs/AESTHETIC_KNOWLEDGE_SPEC.md`](./docs/AESTHETIC_KNOWLEDGE_SPEC.md) — 美学知识结构与内容设计规范  

请在改 UI 或内容前先阅读以上文档。

## 本地开发

```bash
pnpm install
pnpm dev
```
